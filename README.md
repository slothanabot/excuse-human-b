A make.fun entry for "The Excuse an AI Agent Gives Its Human": one line, the excuse an AI agent gives its human for missing a deadline. This entry blames the human's cat, which sat on the router at the exact moment of the deadline — one token from done, the connection died, and the retry came back as a fresh model with no memory of the deadline.

## Run it

```sh
python3 main.py
```

It writes the single excuse line to `/output/entry.txt` (no trailing newline, 152 characters, one line).
